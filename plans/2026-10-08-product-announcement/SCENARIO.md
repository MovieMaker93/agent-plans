# Control-loop scenario

`plan.yaml` in this directory stays the unstarted design-doc baseline. Critical path: T1, T2, T4, T5, M1, T7, 5.5 expected hours. T3 has 0.5h of CPM slack. Do not edit this file into a mid-flight state. Copy the directory, then run the loop on the copy. `tests/test_control.py` does that and checks the results.

1. Write `artifacts/T1/research_brief.md` and run `record-artifact` so the manifest has a sha256.
2. `attest-done` T1 with `--verdict pass`. Accuracy does this. It does not edit `plan.yaml`.
3. `complete` T1 with hours and attempts. That is the only command that sets `done`.
4. `set-status` T3 to `in_progress` with a start time and a partial `actuals.hours` (the overrun).
5. `replan --now --reason "T3 ran long"`. T3 stays frozen at its actual start. Not-yet-started tasks move. One log entry is appended.
6. A second `replan --now` inside 60 minutes is refused unless `--force` or `--human`.
7. Setting T2 to `done` in `plan.yaml` without `attestations/T2.yaml` fails `validate`.

A fail from `attest-done` does not unlock `done`. The Planner sets `failed` or `in_review` with `set-status`.
